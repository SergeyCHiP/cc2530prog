### **Компиляция и запуск:**
```bash

./test_gpio_mock

# Полная версия (для Raspberry Pi)
gcc -Wall -Wextra -g -o test_gpio_enhanced test_gpio_enhanced.c -lgpiod
sudo ./test_gpio_enhanced
```
