## 🚨 Текущая проблема

**Ошибка при идентификации CC2530:**
```bash
sudo ./cc2530prog -i -v
[ERROR] Failed to set direction for GPIO 22
failed to set data gpio direction
failed to identify chip
[ERROR] Failed to set direction on 17
```

**Причины возможны:**
1. GPIO 22/17 заняты другими процессами
2. Проблемы с правами доступа
3. Конфликт с другими GPIO пользователями
4. Неправильная последовательность инициализации
